SPARTACO — Public Cryptographic Challenge for Independent Researchers

I am inviting cryptographers, mathematicians, cybersecurity researchers, and independent developers to examine a set of encrypted artifacts generated by SPARTACO, a cryptographic system developed by me.

I expressly authorize independent cryptanalysis of these files.

All published challenge files belong to me, were generated using my own algorithm, and were prepared specifically for this experiment. They contain no sensitive, private, or confidential information.

The challenge: Attempt to recover the original plaintext from the encrypted artifacts without access to the SPARTACO engine, its internal secrets, or the legitimate account session.

The GitHub repository is intended exclusively to distribute the experimental artifacts and their documentation. It is not a source-code repository and does not contain the SPARTACO engine.

Researchers are welcome to examine the cryptographic structure, test the integrity mechanisms, investigate the encrypted envelopes, and attempt independent decryption.

Successful results should include reproducible technical evidence, the methodology used, and proof of plaintext recovery.

Experimental authorization: Permission is granted to download, inspect, analyze, modify, and attempt to decrypt the published challenge files. This authorization applies only to the experimental artifacts, not to external accounts, infrastructure, or systems.
